# Деление

Выполнить деление целых с заданным количеством знаков после запятой и вывести на экран.

Делимое, делитель и количество знаков после запятой задаются в командной строке.

## Пример

1. Деление числа 22 на число 7 с 20-ю знаками после запятой.

Команда: `divider 22 7 20`

Ответ: `3,14285714285714285714`

2. Деление числа 1 на число 128 с 10-ю знаками после запятой.

Команда: `divider 1 128 10`

Ответ: `0,0078125000`


## Требования
Программа не должна использовать контейнеры STL (std::vector, std::string и т. д.).
